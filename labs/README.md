# Runnable Labs

All five labs run offline. Start at the top and extend the same support-agent project.

| Order | Topic | 中文 |
|---|---|---|
| 01 | [Structured output](lab01_structured_output/README.md) | Mock 分类与类型校验 |
| 02 | [Retrieval evals](lab02_rag_evals/README.md) | 词法检索与指标 |
| 03 | [Tool Calling, Approval and Idempotency](lab03_tool_calling/README.md) | [工具调用、审批与幂等](lab03_tool_calling/README.zh-CN.md) |
| 04 | [Agent State, Checkpoints and Recovery](lab04_agent_state/README.md) | [Agent 状态、检查点与恢复](lab04_agent_state/README.zh-CN.md) |
| 05 | [Agent Evaluation and Regression Gates](lab05_agent_evals/README.md) | [Agent 评测与回归门禁](lab05_agent_evals/README.zh-CN.md) |

Run all checks from the root with `make validate`. New labs are tested in CI. Live models, production auth, distributed workers and representative evaluation datasets are follow-on exercises.
