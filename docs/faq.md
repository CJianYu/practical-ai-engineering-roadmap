# Frequently Asked Questions

## Is this a machine-learning roadmap?

It is primarily an **Applied AI Engineering** roadmap: using models, data, retrieval, tools, and software systems to ship products. It includes enough ML foundations to reason about quality, but it is not a substitute for a model-training curriculum.

## Do I need to finish every course linked here?

No. Use one anchor resource per topic, then build. Return to specialized material when a project failure reveals a gap.

## Which framework should I learn?

First implement one small model/tool loop yourself. Then choose the smallest framework that solves a demonstrated state, orchestration, tracing, or optimization problem. The roadmap does not require a specific vendor.

## Should I learn fine-tuning?

Not in the core 12 weeks. First exhaust clearer prompts, better context, retrieval, tools, data quality, and eval-driven iteration. Fine-tuning becomes useful when you can state exactly which behavior or economics require changing model weights.

## Should I build a multi-agent system?

Only after a single-agent or deterministic workflow has a measured bottleneck that specialization or parallelism can solve. Multi-agent designs add coordination, latency, cost, and error-propagation risks.

## Can I use TypeScript instead of Python?

Yes. The concepts are language-independent. The starter labs use Python because much of the AI tooling and course material does, but equivalent TypeScript contributions are welcome.

## How many hours per week?

The default assumes about eight hours: two for study, five for building/evaluating, and one for writing or explaining results.

## How do I know I am job-ready?

You should be able to demo a deployed system, explain its architecture, show an eval dataset and error analysis, discuss safety and production constraints, and support résumé claims with measured evidence.
