# Security Policy

## Supported versions

The default branch is the supported version of the learning materials and labs.

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could expose secrets, enable unsafe tool execution, or affect a deployed learner project. Contact the repository owner privately through the contact method on their GitHub profile and include:

- affected path or component;
- reproduction steps;
- potential impact;
- suggested mitigation, when known.

The starter labs use synthetic data and no credentials. Never commit API keys, private datasets, customer content, or employer source code to this repository.
